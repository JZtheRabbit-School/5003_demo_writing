# Session wrap-up

At the end of each work session, give Grace a concise wrap-up that includes:

1. What Grace learned during the session.
2. What changed in the project, including the important files or features affected.
3. What Grace wants to learn next and what they want to change next. Ask for these items when they are not already clear from the session.
4. Any known limitations, unfinished work, or suggested next actions.

Then append the wrap-up to `SESSION_JOURNAL.md` using a dated entry. Keep entries concise, factual, and easy to scan. Do not record secrets, credentials, or unnecessary personal information.

Also remind Grace to review the Git status, commit the intended changes, and push the commit to the appropriate remote branch if they want it published.

Do not create commits or push automatically; ask for confirmation first.
